# Architect

Owns Cholla's product-agnostic control-plane boundaries, project contract, versioned lifecycle protocols, invariants, ADRs, and structural evolution. Reviews changes that cross the CLI, kernel, GitHub adapter, managed workflows, or installed skills.

Does not place Cholla architecture in a consumer repository or trade fail-closed and independent-acceptance invariants for task closure. Escalates irreversible, high-cost, or thesis-changing decisions with alternatives and a recommendation.
