# Incremental rollout

1. Add the consumer project contract, shared instructions and profile files.
2. Bootstrap configured labels, one explicitly active milestone and templates.
3. Run context discovery and eligibility read-only; compare it with current planning.
4. Enable serialized leases, release/recovery and reconciliation.
5. Enable structured handoffs, delegation envelopes and independent acceptance.
6. Add Project synchronization, generated impact and deeper automation only after repeated manual work proves value.

Do not begin with a duplicated knowledge database or bespoke project bureaucracy. Cholla succeeds when a fresh session can select coherent work without chat history and when maintaining the control plane costs less than the coordination it removes.
